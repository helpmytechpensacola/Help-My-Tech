# Help My Tech Pensacola

A local tech support web app for Pensacola, FL — helping residents (especially seniors and their families) troubleshoot tech issues and book hands-on help from a real local tech.

## What it does

- **AI-guided troubleshooting** — walks users through common phone, laptop, tablet, and TV issues step by step
- **Carrier outage checker** — live status check across Cox, AT&T, and T-Mobile so users know if it's their device or their provider
- **Booking** — connects users directly to Help My Tech Pensacola for hands-on support when self-help isn't enough
